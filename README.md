
# Student Score Prediction Using Machine Learning

## Project Overview
This project predicts students' final examination scores
using machine learning based on their study habits and
academic performance.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Streamlit

## Features
- Dataset analysis and preview
- Data preprocessing
- Linear Regression and Random Forest models
- Model evaluation using MAE, RMSE, and R2 Score
- Actual vs Predicted visualization
- Prediction error analysis
- Interactive student score prediction
- Downloadable prediction results

## Project Structure
- app.py - Streamlit application
- main.py - Model training script
- data/ - Dataset
- src/ - Source code
- tests/ - Test files
- screenshots/ - Application screenshots
- requirements.txt - Python dependencies

## How to Run

1. Clone or download this repository.
2. Install the required dependencies:

   pip install -r requirements.txt

3. Run the Streamlit application:

   streamlit run app.py

## Project Purpose
This project demonstrates basic machine learning,
model evaluation, data visualization, and deployment
skills for student score prediction.
